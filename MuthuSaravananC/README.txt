MUTHU SARAVANAN — PROJECT, PROGRAM & STRATEGIC ACCOUNT MANAGEMENT PORTFOLIO

FILES
- index.html   Main website content
- styles.css   Responsive executive/corporate design with project, program and strategic account management positioning
- script.js    Mobile navigation and automatic copyright year

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. Internet is needed for the Google Fonts; the site otherwise works without a build step.

PUBLISH FREE WITH CLOUDFLARE PAGES (DIRECT UPLOAD)
1. Create/sign in to a free Cloudflare account: https://dash.cloudflare.com/sign-up
2. Open Workers & Pages: https://dash.cloudflare.com/ (Workers & Pages in the dashboard).
3. Choose Create application / Pages / Direct Upload (wording may vary).
4. Give the project a short name, for example muthu-saravanan-portfolio.
5. Upload the ZIP file or the extracted website folder and deploy.
6. Cloudflare will provide a URL in this format:
   https://YOUR-PROJECT-NAME.pages.dev

IMPORTANT
- Cloudflare's Direct Upload flow is appropriate for this ready-made static website. Cloudflare documents that the project URL uses the pages.dev subdomain.
- Direct Upload projects cannot later be converted to Git integration; create a new Git-integrated project if you later want automatic deployments from GitHub.
- Hosting is intended to use Cloudflare's free plan; check current plan terms and limits before publishing.
- The website contains only a LinkedIn contact link. No email address, phone number or CV file was supplied, so none has been invented.

EDITING
Use any text editor (Notepad, VS Code, etc.). Edit index.html for wording and styles.css for appearance. Re-upload the updated ZIP to Cloudflare Pages to publish changes.
